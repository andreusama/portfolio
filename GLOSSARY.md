# Portfolio

A single personal site that presents one engineer to two kinds of employer: software and games.

## Language

**Entry**:
One of the two audience-facing sides of the portfolio, Software or Games, each with its own set of projects.
_Avoid_: Version, portfolio (when meaning one side), profile

**Software entry**:
The Entry for full stack employers, led by the flagship projects.
_Avoid_: Web entry, dev entry

**Games entry**:
The Entry for game studios and simulation employers, led by the shipped commercial titles.
_Avoid_: Unity entry, Gamedev entry

**Landing**:
The default page, showing the shared headline and the two Hero windows.
_Avoid_: Home, index

**Hero window**:
One of the two clickable windows on the Landing, each opening one Entry.
_Avoid_: Door, card, tile

**Direct link**:
A URL that opens one Entry without passing through the Landing, sent when only one side is relevant.
_Avoid_: Deep link, shortcut

**Flagship project**:
A project chosen to carry an Entry, presented as a Case study.
_Avoid_: Featured project, main project

**Case study**:
The write-up of a Flagship project: problem, stack, own role, key decisions, outcome, and a screenshot or links when they can be shown.
_Avoid_: Project card, project page

**Software CV**:
The one-page CV that leads with Python/Django and TypeScript/React and presents games as real-time experience.
_Avoid_: Dev CV, web CV

**Games CV**:
The one-page CV that leads with the shipped commercial titles and treats software as a complement.
_Avoid_: Unity CV, Gamedev CV
